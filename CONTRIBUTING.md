# Contributing

Open an issue with a synthetic reproducible example and expected behavior. For any new financial rule, provide source, effective period, applicability, version, calculation method, edge cases and evidence of professional review if statutory. Run `python -m unittest discover -s tests -v`. Keep monetary values decimal strings; no binary floating point or arbitrary eval. Never include actual financial data, credentials or copyrighted third-party material without permission. Contributions are licensed MIT. Keep documentation and changelog accurate.
