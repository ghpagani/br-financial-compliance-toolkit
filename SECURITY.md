# Security and privacy

Report vulnerabilities privately through GitHub private vulnerability reporting if enabled; otherwise contact the maintainer privately. Never attach actual payroll, invoices, bank files, personal identifiers or credentials to public issues. Use synthetic reproductions.

Local CLI makes no network calls but does not encrypt files or control access. Use organization-approved storage, least privilege, encrypted devices/backups, pseudonymous references, data minimization, retention/deletion policy and approved execution environments. Do not upload real data to agent hosts by default. Review Git diffs before publishing; .gitignore does not guarantee prevention of disclosure. If secrets are exposed, rotate them and follow incident response procedures; making a repository private is not sufficient.

Outputs may be sensitive. Do not run untrusted code or files with elevated privileges. No payment execution or automatic adverse decisions. Human reviewer is responsible for interpretation.
